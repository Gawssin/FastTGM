# FastTGM
 
**FastTGM** is an exact counting framework for seed-rooted temporal motifs. It combines future-equivalent state compression with slack-aware completion pruning to efficiently count larger motifs and support applications such as fraud detection. 

The corresponding paper, [**FastTGM: Efficient Seed-Rooted Temporal Motif Counting with Compressed States**](https://doi.org/10.1145/3856343), has been accepted to **SIGMOD 2027**; the [full version](https://github.com/Gawssin/FastTGM/blob/main/FastTGM-Full-Version.pdf) includes additional proofs and baseline pseudocode.
